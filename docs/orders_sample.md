DKH-3159547 - Hafele DROPSHIP 


Step 1 - Cx verification

Checked billing and shipping address with cx details and their relation to the addresses provided using google and whitepages.

Scorlled down to check payment method

* If payment method is credit card Then made sure POSTAL CODE SHOWS (M) and STREET ADDRESS MATCHES (M) if it doesn't show both as (M)(M) then verified cx details more thoroughly and checked if cx has any previous orders with the same Credit Card and Addresses.

*if payment method anything other than Credit card (ApplePay, Paypal, AmazonCheckout) then no thorough verification is required. Just make sure if cx has entered correct address details by checking using Gmaps or BingMaps


Step 2 - Checking item 

* Click on the item code to open the item page on Vendor Website.
* For This specific order we enter the qty required in the empty field below the item. It loads for a second and shows the entered quantity below and stock next to it 
* Compared the item on vendor website to the item on our website by clicking the item description which is to the right side of the item code. Made sure item code, Item description and item specifications match.


Step 3 - Decision Making 

* Keeping the rules for Hafele in mind. This item qualifies for dropship since it is above $10 and is in stock.
* Cx details have also been verified and good to go. (IF SHIPPING ADDRESS IS A PO BOX NUMBER THEN IT IS ADVISABLE TO MOVE IT INHOUSE)


Step 4 - Creating a dropship 

* Click on the BLUE BUTTON that says (Process incoming Order page)
* In The first box assign the item qty 
* Scroll down and click on Authorize and charge button which is blue
* Scroll Down and click on Create new order option and select the dropship option
* Scroll Down and Click Process Changes to create a dropship.


Step 5 - Processing the Dropship

* Open the Dropship Vendor Order by going to cx order and scrolling down to order notes. We can see that item qty was assigned to an order. Click on the order to open the dropship vendor order.

* Once the order is open check everything one last time and make sure correct quantities are assigned 

* Scroll down and click on (CREATE PO) option on the right side.
* A new page opens. Here we dont need to change shipping method since it is not an expedited order 
* Click on (PLACE ORDER) to process 

THE ORDER HAS BEEN PROCESSED
